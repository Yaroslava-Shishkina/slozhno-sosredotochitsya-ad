# Сложно сосредоточиться

Адаптивный лендинг о причинах, которые мешают сосредоточиться, и способах улучшить концентрацию. В оформлении доступны светлая, автоматическая и неоновая темы; выбранная тема сохраняется в браузере.

Проект сделан на HTML, CSS и JavaScript без сборки и дополнительных зависимостей.

## Запуск

Откройте `index.html` в браузере.
Ссылка на репозиторий: https://github.com/Yaroslava-Shishkina/slozhno-sosredotochitsya-ad
